# Cosplabuilder
Website for cosplay building assistance - create, plan, and track cosplay progress online, across any device. Made for KTU module T120B165 "Web Application Design".
(Translation to be updated)

Projekto tikslas – palengvinti kūrybininkams kostiumų, papuošalų, dekoracijų ir kitų objektų planavimą, kūrimą, bei progreso stebėjimą, teikiant vientisą planuoklio paslaugą.
Veikimo principas – dviejų dalių platforma: internetinė aplikacija, kuria naudosis kūrybininkai ir administratoriai, bei aplikacijų programavimo sąsaja (angl. trumpinys API).
Projekto tikslinė auditorija – kūrybinių industrijų darbuotojai, profesionalūs ar mėgėjai kosplayėriai ar kitokiais kūrybiniais hobiais (pvz. juvelyrika, mezgimas, medžio apdirbimas ir kt.) užsiimantys naudotojai, kuriems praverstų vientisa kūrybinių projektų planavimo sistema.
Vartotojas, norėdamas naudotis šia platforma, turės prisiregistruoti prie internetinės aplikacijos. Prisijungęs galės susižymėti turimus įrankius, medžiagas, ar kurti projektus. Projektui galima pridėti dalis. Projekto dalys gali turėti aprašymus, priskirtas medžiagas, instrukcijas, kainas, užduotis bei užduočių trukmes. Vartotojas taip pat mato projekto bendrą suvestinę – kokia bendra projekto kaina bei užtruktas laikas. Administratoriai galės peržiūrėti svetainės naudojimo statistiką, reaguoti į praneštas klaidas ir pasiūlymus, atstatyti ar trinti kitų vartotojų paskyras. Svečiai matys tik platformos aprašymą ir registracijos bei prisijungimų puslapius.
